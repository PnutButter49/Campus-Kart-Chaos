# Campus Kart Chaos

An original browser-based college-themed arcade kart racer created for a class extra-credit project.

## Modes
- Campus Cup
- Quick Race
- Time Trial
- Online Race (2–4 players with Supabase Realtime)

## Controls
- W / Up: accelerate
- S / Down: brake/reverse
- A / Left: steer left
- D / Right: steer right
- Space: drift
- E: use item
- P: pause / race menu

## Backend
Supabase is used for anonymous cloud saves, online leaderboards, and Realtime lobby/race synchronization. No email, real name, or account is required by the game.
